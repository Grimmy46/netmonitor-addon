Running it on a handheld
  1. Any Android terminal with a laser or imager engine works the same way a USB gun does — it types the decoded code into whatever field has focus.
  2. On Zebra, open DataWedge, pick the profile bound to the browser, and set Keystroke output on with an Enter action suffix.
  3. On other terminals look for "keyboard emulation", "keyboard wedge" or "HID output" in the scanner settings app, and add a carriage-return suffix.
  4. No Enter suffix available? Leave Accept scans with no Enter suffix on and the station commits each burst itself.
  5. Tap the scan box once so it holds focus, then work the trigger. The lamp turns amber if focus is ever lost.
